## ✨ Overview

Gorgon's Wrath is a 3D atmospheric action–evasion game developed in Unity. You play as **Lyra**, trying to escape an ancient forest guarded by a dynamic AI creature called the **Gorgon**, while collecting soul essences to survive and progress through levels.

---

## 🎯 Core Features

🧠 **Adaptive AI System**  
The Gorgon uses a PathFollower-based system that tracks player movement and adapts its chasing behavior dynamically.

🔄 **Game Flow System**  
Managed by GameManager and TransitionManager to handle scene transitions and overall progression.

💎 **Collectible System**  
Players collect soul essences using the Collectible script to unlock progression.

🌲 **Atmospheric Level Design**  
Three handcrafted levels with increasing difficulty and immersive forest environments.

## 🚀 Getting Started

1. Open the project in Unity  
2. Go to:
   Assets/Scenes/MainMenu  
3. Press Play  
4. Ensure all prefabs are assigned correctly in the Inspector
